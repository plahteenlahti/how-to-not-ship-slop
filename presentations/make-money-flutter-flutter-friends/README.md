# Make money with your Flutter app

Open `index.html` in a browser or serve this directory with any static file
server.

## Edit the text

All slide text lives directly in `index.html`. Search for comments such as
`SLIDE 14 — TRIAL LENGTH`, then edit the text inside that slide's `<section>`.
Speaker notes are in the `<aside class="speaker-note">` at the end of each
slide.

For quick edits while presenting, press `E`, click into the visible text, and
type. Quick edits are saved in that browser's local storage; they do not rewrite
the HTML file. Press `Escape` to leave edit mode.

## Present

- Left / Right, Page Up / Page Down, or Space: navigate
- Home / End: first or last slide
- `F`: fullscreen
- `N`: speaker notes
- `E`: edit visible text
