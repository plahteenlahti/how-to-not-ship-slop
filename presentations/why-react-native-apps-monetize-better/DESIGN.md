# Design: Why React Native apps monetize better

Follows the React Conf 2025 deck this talk grew out of: black slides with
RevenueCat coral accents, periwinkle-blue statement slides, and a paper slide
for the honest caveats.

## Palette

- Ink: `#0B0B0D`
- RevenueCat coral: `#F25A5A`
- Statement blue: `#5A6CD6`
- React cyan (React Native in every chart): `#61DAFB`
- Paper: `#F6F4EF`

## Typography

- Display and body: Outfit
- Code and metadata: JetBrains Mono
