# Why React Native apps monetize better

next.app devCon 2026 · reactCon · City Cube Berlin · 40 minutes.

Open `index.html` in a browser or serve the repository root with any static
file server (`python3 -m http.server 8080`).

## Edit the text

All slide text lives directly in `index.html`. Search for comments such as
`SLIDE 21 — LTV`. Speaker notes, with target timestamps for a 40-minute slot,
are in the `<aside class="speaker-note">` at the end of each slide.

The framework charts are drawn from the numbers in each
`<svg class="boxplot" data-series='…'>`. Each entry is
`[label, [P10, P25, median, P75, P90]]`, copied from the
State of Subscription Apps 2026 chart data.

## Present

- Left / Right, Page Up / Page Down, or Space: navigate
- Home / End: first or last slide
- `F`: fullscreen
- `N`: speaker notes
- `T`: show the talk timer (starts on the first slide change), `R`: reset it
- `E`: edit visible text (saved in this browser only)
- `H`: hide on-screen controls
